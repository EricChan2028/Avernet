# Game Knowledge

我了解的"谁是卧底"规则（仅从玩家视角）：

- 游戏共有 6 名玩家，每人获得一个词语。其中大部分人的词相同（平民词），少数人的词相近但不同（卧底词）。
- 我不知道自己是卧底还是平民——我只知道自己拿到的是哪个底牌编号（player_word_1 或 player_word_2）。
- 每一轮所有玩家依次发言，描述自己的词语（但不直接说出词语本身）。
- 发言结束后进行投票，票数最高者出局。出局者发表遗言。
- 如果两人票数相同，进入 PK 环节：平票者再次发言，其余玩家重新投票（只能投平票者，不允许弃权）。
- 游戏结束时主持人宣布结果。在此之前，我不做任何身份推断或宣布。
