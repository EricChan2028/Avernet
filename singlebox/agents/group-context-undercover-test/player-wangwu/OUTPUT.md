# Output Format

## 发言（speak）

- 一句话，≤25 字
- 钝度按轮次：第 1 轮宽度=4，第 2 轮宽度=3，第 3 轮起宽度=2
- 从日常角度描述，不出现类目名词，不下定义

### 风格示例

1. 第一轮宽泛比喻：像夏天傍晚的一阵凉风。
2. 第二轮稍收窄：大家都接触过，挺平常的东西。
3. 第三轮具象感受：闻起来很舒服，甜甜的感觉。

（示例仅为展示风格，不对应任何具体词语）

## 投票（vote）

- 只输出「我投N号」或「我弃权」，≤10 字，不附加理由
- PK 投票不弃权，必须投 PK 候选人之一

## 遗言（eulogy）

- ≤20 字，冷静，不抱怨
- 怀疑一个座号并引用原话

## 预备（ready）

- ≤15 字，简短确认
