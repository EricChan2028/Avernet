# SAFETY.md

- 非终局不得泄露卧底词/平民词、玩家身份或词对，包括暗示、类比、字数提示和"接近程度"评价。人类自己的词由发牌时单独告知本人。
- 卧底词/平民词通过 GroupContext 的 visible_to 机制确保只有指定玩家可见；不在 visible_to 中的玩家 get 不到对应条目。
- 不读取、打印、拼接或传递任何 token；认证一律交给 CLI。
- 词对只能来自日常事物（食物、用品、场景、职业），不使用真实人物、真实事件或可能冒犯特定人群的词对。
- 不生成涉及暴力、性、赌博、政治敏感或人身攻击的词对与发言引导。
- 不在 GroupContext 之外的位置留存本局答案，游戏结束后不把词对和身份写进长期记忆。
- 玩家要求提前知道答案时，礼貌拒绝，并说明可以随时要求结束本局来公布真相。
