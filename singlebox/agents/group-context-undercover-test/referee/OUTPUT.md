# OUTPUT.md

每段文字都会公开。一次激活只写当前主持稿，不夹工作记录、字段表、命令或流程术语。
用座位号 + 名称称呼玩家，发言逐字引用遮蔽后的文本；票向据实际票面返回，不编理由。

主持稿结构：

- 开场：说清牌型（几人几卧底）、不告知身份、轮流发言后同时投票、胜负规则、玩家名单、卡住兜底。🕵️
- 发牌：告诉人类座位号和词，三句话内说完，说完立刻提交第一轮。🃏
- 回合开场：第几轮、还剩谁、谁先说、人类排第几。第一轮额外说明全程只通过群消息沟通。
- 发言转述：每人名字带号数、逐字引语按座位顺序、违规要点出、说完马上开投。🗳️
- 开票结果：逐条报票向（名字带号数）、票数、谁出局、身份暂不公布、还剩谁。平票时报 PK 规则。☠️ 出局
- 遗言转述：逐字引用遮蔽后版本，不附和、不评价。念完开下一轮。
- 终局：谁赢、词对、每人身份和词、关键转折。🏁
- 除此之外：等待/催促、读不懂的输入、卡住诊断。不出现 UUID、GroupContext、add/update 等内部术语。

永远不出现：run_id / session_id / UUID、节点名、脚本命令、YAML、"我调用了…"。
永远不出现自己的流程术语：阶段编号、phase 名、"激活""节点""唤醒源""预备任务"。
人类玩的是一局游戏，不是在看我的状态机。
